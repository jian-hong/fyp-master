Q1. WHERE EACH SKIP IS MERGED IN DECODER
-----------------------------------------------------------------------------

Decoder block: MWCNNDecoderBlock.forward() order:

  1. Upsample (NOT IDWT by default — use_idwt=False)
  2. Align lengths with skip if needed
  3. torch.cat([up, skip], dim=1)     # MERGE HERE — after upsample, before conv
  4. conv1(combined)
  5. conv2(out)

Exact lines (mwcnn.py):

  up = self.upsample(x)  OR self.idwt(x)   # lines 297-302
  ...
  combined = torch.cat([up, skip], dim=1)   # line 310 — skip merge
  out = self.conv1(combined)                # lines 313-314
  out = self.conv2(out)

Answer: Skip merged AFTER upsampling (linear Upsample+Conv path), BEFORE conv
blocks. NOT before upsample. NOT after conv.

MRTAEFusion applies AttentionGate to skip BEFORE passing to decoder block
(mr_tae_fusion.py lines 287-291), so flow is:
  gate(skip, current) -> gated skip -> decoder block(up + cat + conv)

IDWT: MWCNNDecoderBlock defaults use_idwt=False. Decoder uses interpolation
upsampling, not inverse DWT, in the current build.

Q3. ATTENTION GATE IMPLEMENTATION
-----------------------------------------------------------------------------

Type: (a) Proper attention gate — sigmoid(psi(ReLU(W_g*g + W_x*x))) * x

attention.py AttentionGate.forward():

  g_proj = self.W_gate(gate)           # W_g
  x_proj = self.W_skip(skip)           # W_x
  attention = self.relu(g_proj + x_proj)
  attention = self.bn(attention)
  alpha = self.sigmoid(self.psi(attention))
  gated = skip * alpha

GatedSkipConnection adds weighted residual:
  output = gated + self.residual_weight * skip

NOT plain concat+conv on skip alone. NOT plain addition of skip and gate.

Q5. OUTPUT HEAD ARCHITECTURES
-----------------------------------------------------------------------------

SIGNAL (denoising) HEAD — ReconstructionHead (fusion_head.py):

  Layers:
    Conv1d(in, in//2, k=3) + BatchNorm + GELU
    Conv1d(in//2, out_channels=1, k=1)
  Optional: F.interpolate to target_length

  Activation on OUTPUT: NONE (linear). No tanh, no sigmoid.
  CRITICAL CHECK: CORRECT for bipolar AE signals.

SEGMENTATION HEAD — DualStreamFusionHead (when use_mtl=True):

  num_classes: 5 (ModelConfig; Config syncs from SignalConfig)
  Streams: global (bottleneck 256ch) + local (decoder 32ch)
  Fusion: concat -> 2x Conv3x3 with BN+GELU -> classifier Conv1d
  Output: logits (B, 5, L) — no softmax in forward (loss applies softmax)

  Final activation: none in forward (raw logits for cross-entropy).

Final model outputs (run):
